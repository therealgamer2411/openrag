# OpenRAG Desktop Runtime (Windows)

This adapter runs the shared OpenRAG Node Runtime worker as a Windows Service, so task polling and execution do not depend on Chrome or an open browser tab.

## Prerequisites
- Windows 10/11 or Windows Server.
- Node.js 20 or newer installed system-wide.
- A configured coordinator reachable from this machine.
- Separate OPENRAG_API_TOKEN and OPENRAG_NODE_TOKEN values generated by the operator.

## Setup
1. Configure node-runtime/.env using node-runtime/.env.example.
2. Set OPENRAG_COORDINATOR_URL to the reachable coordinator URL.
3. Run npm install inside the node-runtime directory to install its runtime dependencies.
4. Run npm install inside persistence-lab/desktop-runtime to install the Windows service wrapper.
5. Open an elevated terminal in persistence-lab/desktop-runtime and run node install.js.

The service launches node-runtime/src/worker.js and restarts it if it exits. The service runs independently from the browser. The task worker currently executes only the allowlisted echo, sha256 and sum task types.

## Important
- The node-runtime package and its dependencies must be installed before installing the service.
- Configure secrets in node-runtime/.env or the Windows service account environment. Never commit .env files.
- Uninstall the service with the node-windows uninstall flow before removing the runtime.
- This is not yet a sandbox for arbitrary third-party code or GPU jobs.
